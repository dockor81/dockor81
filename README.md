## Как я работаю

- **Цель важнее инструмента.** Сначала понимаю, какой результат нужен бизнесу, потом выбираю каналы и средства.
- **Решения на данных.** Опираюсь на проверяемые цифры, а где их нет, честно называю оценку оценкой.
- **Прозрачные изменения.** Каждое изменение согласовано, понятно и его можно отменить.
- **Результат проверяется.** Эффект оцениваю по цифрам «до» и «после», а не по ощущениям.
- **Коротко и по делу.** Сначала суть и решение, потом подробности.
- **Бережно к данным людей.** Собираю только то, что нужно для решения, без лишних персональных данных.
